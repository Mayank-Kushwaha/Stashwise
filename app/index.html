Settings

The Vault needs two free keys: a GitHub token to sync your bookmarks between devices, and a Gemini key for the AI. Both stay on this device only.

1
GitHub tokenSyncs your library through a private Gist
How to get a GitHub token
  1. Sign in to GitHub. Your email address must be verified.
  2. Open New personal access token (classic). This link fills in the name and ticks gist.
    Manual route: profile picture → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → Generate new token (classic).
  3. Note: type a name, e.g. AI Bookmark Vault.
  4. Expiration: pick a date. Sync stops when the token expires, so choose a long period and make a new token when it ends.
  5. Scopes: tick only gist. Leave everything else unticked so the token can't touch your repositories.
  6. Click Generate token, copy it (it starts with ghp_, and GitHub shows it only once), and paste it above.
2
Gemini API keyWrites titles and topics, and powers Ask AI
How to get a free Gemini key
  1. Open Google AI Studio → API keys and sign in with your Google account.
  2. New users: accept the Terms of Service. AI Studio then creates a default project and key for you.
  3. Otherwise click Create API key and choose a project. If you already use Google Cloud, you may need to import a project first: Dashboard → Projects → Import projects.
  4. Copy the key and paste it above. No billing is needed for the free tier.

On the free tier, Google may use what you send to improve its products. Private sites and anything on the never-send list below are never sent.

3
Your data GistCreated automatically on the first sync

Using the Vault on another device or your phone
  1. Install the extension on the other browser, or open the phone app and choose Add to Home screen.
  2. Paste the same GitHub token and your Gemini key there.
  3. Press Save. The Vault finds this Gist by itself, so you never need to copy its ID.

The Gist is "secret": it's not listed publicly, but anyone with its link can read it. Don't share the link.

Advanced

Get the browser extension

The extension adds one-click saving (toolbar icon, Alt+Shift+S, right-click), nightly address checks and preview images. It isn't in a web store, so you install it yourself in about a minute.

ai-bookmark-vault.zipAlways the latest version from GitHub
Download

    Updating to a new version
    1. Download the zip again and extract it into the same folder, replacing the old files.
    2. On the extensions page, click the reload ↻ icon on the AI Bookmark Vault card.
    3. Keep using the same folder. The browser ties your settings to the folder's location; loading from a new folder starts fresh (your bookmarks come back after you paste the GitHub token again).
